Microsoft-ecosysteem

VirtualPC + Microsoft Copilot

VirtualPC vult Microsoft Copilot aan. Copilot helpt gebruikers met snelle antwoorden; VirtualPC voert achter de schermen complexe, autonome workflows uit met rollen, governance en audit.

Technische integratie Pricing Agent roster

Wie doet wat?

Ze zijn geen concurrenten. Copilot zit aan de voorkant, VirtualPC aan de achterkant.

🟦 Microsoft Copilot

Gebruikersgerichte AI in Office, Teams en Windows. Ideaal voor snelle antwoorden, samenvattingen, concepten en chat.

🟪 VirtualPC

Multi-agent operating system met eigen geheugen, takenmotor en governance. Voert processen end-to-end uit en houdt mensen in de lus.

🤝 Samen

Copilot vraagt iets, VirtualPC voert het uit. Resultaten komen terug in Teams, Outlook of SharePoint waar de gebruiker al werkt.

Integratiepunten

VirtualPC praat via standaard protocollen met de Microsoft-stack.

Entra ID (Azure AD)

SSO en rollen via SAML/OIDC. JWT-claims bepalen de VirtualPC-rol van de gebruiker.

Microsoft Graph

Lees Teams-berichten, SharePoint-bestanden, Outlook-mail en agenda. Schrijf resultaten terug.

Azure OpenAI

Gebruik GPT-4o of o-series als cloud-fallback in de LiteLLM-gateway, naast lokale Ollama-modellen.

Copilot Studio

Start VirtualPC-taken vanuit een Copilot-actie of custom topic. VirtualPC wordt zo een backend-skill.

Power Automate

Trigger workflows wanneer een SharePoint-item wijzigt of een Teams-bericht een bepaald keyword bevat.

Azure DevOps / GitHub

Agenten openen PR’s, reviewen code en updaten work items net als menselijke teamleden.

SharePoint / OneDrive

Datasets en rapporten leven in de bestaande documentenbibliotheken; Governor houdt lineage bij.

Azure Monitor

Stuur logs, metrics en agent-vitals naar Application Insights of Log Analytics.

Scenario’s

📧 Verkooprapportage uit Outlook en CRM

Een salesmanager vraagt in Teams: "Wat zijn onze top-5 kansen deze maand?" Copilot geeft een kort antwoord. VirtualPC start de Analyst-agent, die e-mails uit Outlook en deals uit Dynamics/SharePoint analyseert, Governor registreert de bronnen, en Pixel post een interactief dashboard terug in het Teams-kanaal.

📊 Compliance-scan op SharePoint

Power Automate detecteert een nieuw gedeeld bestand. Governor scant het op PII en licenties, Analyst maakt een risico-rapport, en Athena keurt het goed voordat het in productie komt. Het resultaat komt terug als SharePoint-listitem.

💻 Software-architectuur na een Teams-meeting

Na een meeting vraagt een productowner: "Kunnen we dit featureverzoek inschatten?" VirtualPC laadt de transcriptie via Graph, Kai en de dev-agents breken het op in subtaken, en de burndown verschijnt in Azure DevOps.

Gegevens blijven binnen je eigen tenant. VirtualPC kan draaien op een Azure VM, Vultr-instance of on-premise server.

Voordelen voor Microsoft-klanten

Geen rip-and-replace

Je huidige Microsoft-licenties blijven intact. VirtualPC is een extra laag achter Copilot.

Data blijft in de tenant

Lokale Ollama-modellen en Azure OpenAI binnen je eigen abonnement. Geen datalek naar externe SaaS.

Schaalbaar team

Voeg zoveel agents toe als je wilt zonder extra FTE. De taakmotor verdeelt het werk.

Audit en governance

Elke agent-actie wordt gelogd. Deliberation gates zorgen dat kritieke beslissingen altijd menselijke goedkeuring krijgen.
