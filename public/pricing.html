Frequently asked questions

Do I need a GPU?
No. The open-source version works fine on CPU with smaller Ollama models. For fast local inference, any CUDA GPU with 16 GB+ VRAM is recommended.
Is there a per-token fee?
No. You bring your own API keys or run local models. VirtualPC itself does not mark up LLM usage.
Can I add my own agents?
Yes. Add an entry to src/agent-registry.ts, and every dashboard picks it up automatically.
What is the commercialization module?
Croesus drafts promotion proposals with bounded budgets. Real spending requires PROMO_REAL_MONEY=1 plus human approval.
